# ADR-001 実行形態とVRM自前実装

- 日付: 2026-06-11
- 状態: Accepted

## 状況
VRChat向けアバター作成ツール。初心者の導入障壁（インストール・Unity・Blender）を最小化したい。C4(GitHub公開)・C5(PII徹底防止)・依存ゼロ既定が制約。

## 決定
**単一HTML（依存ゼロ・raw WebGL・CPUスキニング）+ VRM 0.x書き出しを純粋JSで自前実装**する。アップロードは行わずVRM出力までを責務とする。

## 根拠
- 配布= URLかファイル1個。初心者導線が最短
- 通信ゼロをコードレベルで保証可能（fetch等が存在しない）
- VRM=glTF(GLB)+JSON拡張であり、Three.js等なしで完全制御可能。出力品質の説明責任を自前で持てる
- VRChat規約: アップロードはSDK限定 → 直接アップロードは恒久スコープ外が正しい

## 却下した代替案
| 案 | コスト | 保守 | 性能 | 却下理由 |
|----|-------|------|------|---------|
| A: Unityエディタ拡張(C#) | 高(Unity前提) | 中 | 高 | 初心者の障壁=Unityそのもの。本末転倒 |
| B: Python CLI+GUI | 中 | 中 | 中 | GUI配布が重い。FBX/3Dプレビューが依存ゼロで困難 |
| C: Web+Three.js/CDN | 低 | 低 | 高 | 依存ゼロ既定に反する。CDN=通信発生・供給網リスク |
| 採用: 単一HTML自前 | 中 | 高 | 中 | 上記すべて充足。トライアングル数が少なくCPUスキニングで十分 |

## 結果（後日追記）
- v0.1.0: 1メッシュ/1マテリアル構成によりQuest最上位Rankを既定達成。テストはscript抽出方式でNode実行可。
